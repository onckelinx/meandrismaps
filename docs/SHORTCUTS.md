# Keyboard shortcuts

`Mod` is <kbd>⌘ Cmd</kbd> on macOS and <kbd>Ctrl</kbd> on Linux. In the app, press <kbd>F1</kbd> (or `Mod+/`)
to see this list.

## Writing

| Action | Keys |
| --- | --- |
| Add child (and start typing) | <kbd>Tab</kbd> |
| Add sibling below | <kbd>Enter</kbd> |
| Add sibling above | <kbd>Shift+Enter</kbd> (when not typing) |
| New line inside a topic | <kbd>Shift+Enter</kbd> (while typing) |
| Finish typing | <kbd>Esc</kbd> |
| Finish typing and move to another topic | an arrow key at the edge of the text |
| Edit selected topic | <kbd>F2</kbd> or double-click |
| Replace selected topic's text | just start typing |

While typing in a **new** topic:

- <kbd>Enter</kbd> / <kbd>Tab</kbd> finish it and add the next sibling / child.
- Leaving a new topic **empty** (<kbd>Esc</kbd> or <kbd>Enter</kbd>) removes it again.
- <kbd>Tab</kbd> on an **empty** new topic indents it under the topic above (outliner style).
- <kbd>Shift+Tab</kbd> moves it up a level.

Arrow keys while typing move the text cursor. At the edge of the text they finish the topic and move on:
<kbd>↑</kbd>/<kbd>↓</kbd> from the first/last line, <kbd>←</kbd> at the start, <kbd>→</kbd> at the end
(same directions as when a topic is selected). With <kbd>Shift</kbd> or text selected they only move the cursor.

## Structure

| Action | Keys |
| --- | --- |
| Move up a level (outdent) | <kbd>Shift+Tab</kbd> |
| Move up / down among siblings | <kbd>Alt+↑</kbd> / <kbd>Alt+↓</kbd> |
| Collapse / expand | <kbd>Space</kbd> |
| Delete topic (and its branch) | <kbd>Delete</kbd> / <kbd>Backspace</kbd> |
| Add / remove boundary | `Mod+B` |
| Topic menu | <kbd>Shift+F10</kbd> or the Menu key |
| Move a branch | drag it onto a topic (child) or onto the top/bottom edge of a topic (sibling) |

## Navigation and view

| Action | Keys |
| --- | --- |
| Select nearby topic | <kbd>↑ ↓ ← →</kbd> |
| Select central topic | <kbd>Home</kbd> |
| Find | `Mod+F`, then <kbd>Enter</kbd> / <kbd>Shift+Enter</kbd> for next / previous |
| Fit map to view | `Mod+1` |
| Actual size | `Mod+0` |
| Zoom in / out | `Mod+=` / `Mod+-`, mouse wheel, pinch |
| Pan | drag empty canvas, <kbd>Shift</kbd>+wheel for horizontal |

## Document

| Action | Keys |
| --- | --- |
| New / Open / Save / Save As | `Mod+N` / `Mod+O` / `Mod+S` / `Mod+Shift+S` |
| Undo / Redo | `Mod+Z` / `Mod+Shift+Z` (also `Ctrl+Y` on Linux) |
| Copy / Cut / Paste branch | `Mod+C` / `Mod+X` / `Mod+V` |
| Insert image | `Mod+Shift+I` |
| Print | `Mod+P` |
| Close window / Quit | `Mod+W` / `Mod+Q` |

Pasting an image while a topic is selected attaches it to that topic; with nothing selected it becomes a
free image. Pasting text creates topics from its outline (indented lines, bullets or Markdown headings).
